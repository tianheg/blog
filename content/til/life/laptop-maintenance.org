#+TITLE: 笔记本保养——如何尽可能延长使用寿命
#+STATUS: draft
#+HEADER: Consumption

以机械革命翼龙 15 Pro 2026（AMD Ryzen 7 H 255 + RTX 5060 115W）这类高功耗密度性能本为例。寿命瓶颈集中在四个地方：高温衰减、供电模组老化、电池损耗、散热通道堵塞。笔记本寿命的四大杀手：高温、满电高压、深度放电、灰尘。

* 电池与充电

锂电池衰减的两大元凶：长期 100% 满电的高电压状态、高温环境。

- 浅充浅放：日常维持电量在 20% - 80% 之间，不要等到低于 20% 才充电，更不要用到自动关机（深度放电对电芯造成不可逆损伤）
- 长期插电办公：官方控制中心支持的话，把充电上限设为 60% - 80%，这是延长电池物理寿命最有效的手段
- 长期存放（超过一个月不用）：电量充至 50% - 60% 后关机存放
- 高负载结束不要立刻拔电：游戏/渲染时 GPU 处于 115W 满功耗，突然拔电系统会瞬间切换到电池供电并剧烈降频，高电流波动冲击电池和 VRM 供电模组。先退出软件，等风扇空转 30 秒吹走余热再拔

无官方控制中心的方案（纯净 Win11，未装厂商软件）：

- 手动拔插 + 带开关的排插：桌面固定使用时，用带独立开关的排插控制物理断电，避免频繁拔插 DC/Type-C 口导致焊点松动或脱焊
- 第三方"充电限制"软件基本无效：充电截止由 EC/BIOS 硬件层控制，通用软件（如 Battery Limiter）只能在达到设定电量时发提醒让你手动拔，无法硬件层面阻断充电

* 散热与物理维护

- 垫高底座：本机为底部进风、四出风口设计。D 面垫高 2 - 3 cm，进风量提升 20% - 30%，核心温度降 3 - 5°C。严禁放在床上、沙发等软质表面使用——进风口完全堵死，硬件瞬间撞温度墙
- 不要用键盘膜：性能本键盘缝隙兼作辅助进风与散热，键盘膜严重阻碍散热；高负载后合盖，热量积聚可能损伤液晶层
- 定期清灰：3 - 6 个月/次。双高转速风扇极易在散热鳍片内侧积"灰尘墙"，用皮老虎/压缩空气缸反向吹出鳍片灰尘
- 拆机安全铁律：拆 D 面清理风扇前先断开电池排线，按压电源键 5 秒释放残余电量再操作，防止金属工具误触主板短路
- 导热介质维护：1 - 2 年/次。原厂硅脂在长期 85°C+ 高温下易发生"泵出效应"干涸，若 CPU/GPU 易瞬间撞温度墙（95°C/87°C），更换为相变导热片（如 Honeywell PTM7950）或高黏度硅脂

* SSD 保护

- 验证并启用 TRIM：管理员 CMD 运行
#+BEGIN_SRC
fsutil behavior query DisableDeleteNotify
#+END_SRC
返回 0 表示已启用；返回 1 表示未启用，执行
#+BEGIN_SRC
fsutil behavior set DisableDeleteNotify 0
#+END_SRC
- 禁用休眠：Win11 默认休眠每次把内存数据完整写入 SSD，管理员 CMD 运行 =powercfg -h off= ，立即删除系统盘根目录的 hiberfil.sys，既省空间又大幅减少写入磨损
- 保留余量：SSD 至少保留 15% - 20% 空闲空间，方便主控做垃圾回收（GC）和磨损均衡，防止写放大
- 不要碎片整理：Win11 对 SSD 只执行 TRIM 优化（设置里搜"优化驱动器"确认优化类型为 TRIM），绝对不要手动对 SSD 做传统磁盘碎片整理
- 迁移高频写入：浏览器缓存、下载目录等频繁写入的文件夹迁移到非系统盘

* 系统纯净与性能调度

极简理念：不装第三方"杀毒/优化管家"，Windows Defender 足够。第三方管家频繁扫描磁盘，增加 SSD 写入量和 CPU 占用，反而损耗硬件。

- 禁用无用服务：services.msc，把 Connected User Experiences and Telemetry（遥测）、SysMain 设为手动/禁用，减少无谓后台读写
- 清理自启：任务管理器 → 启动应用，禁用所有非必要的第三方开机自启项
- 电源模式：设置 → 系统 → 电源与电池。插电重度场景（游戏/编译）用"最佳性能"，移动/日常用"平衡"或"最佳电源效率"，抑制 CPU 盲目冲高频
- 驱动更新：不装厂商捆绑软件，但底层驱动要手动更新——CPU 芯片组去 AMD 官网下载，显卡去 NVIDIA 官网下载（安装时勾选"执行清洁安装"）

* 浏览器缓存（减少 SSD 写入）

Firefox：地址栏 about:config 设置

- browser.cache.disk.enable → false （禁用磁盘缓存）
- browser.cache.memory.enable → true （启用内存缓存）
- browser.cache.memory.capacity → 524288 （即 512MB，用大内存代替 SSD 读写）

Edge（Chromium 内核没有 about:config，用启动参数）：右键快捷方式 → 属性 → 目标末尾加参数

#+BEGIN_SRC
--disk-cache-size=104857600
#+END_SRC

（限制磁盘缓存最大 100MB，达到后自动用内存管理临时缓存，不再大文件写入 SSD）

配合浏览器自带的标签页休眠/效率模式，后台标签页会自动释放 CPU 和内存，降低发热和写盘。

* 接口与机身保护

- 插拔接口平行受力：Type-C、HDMI、电源口频繁受侧向力会导致 PCB 焊点松动或脱焊
- 拒绝热合盖：高负载运行完毕后让笔记本静置 1 - 2 分钟待风扇停转再合盖，防止机身余热烫伤屏幕液晶层
- 屏幕清洁：关机断电后用超细纤维布（如眼镜布）微湿擦拭，不要把液体直接喷在屏幕上，禁用含酒精或强腐蚀性溶剂（会破坏屏幕镀膜）
- 规范关机：除非死机，不要长按电源键强制关机，防止写入中断损坏文件系统或 SSD 映射表
