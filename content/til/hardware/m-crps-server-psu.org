#+TITLE: M-CRPS 服务器电源
#+STATUS: draft
#+DATE: 2026-08-22T10:18:25

M-CRPS (Modular Hardware Common Redundant Power Supply) 是 OCP (Open Compute Project) 主导的服务器电源标准，CRPS 的下一代演进，为 AI 服务器的供电而生。

*核心升级逻辑：* AI 服务器 GPU 功耗如同过山车，7×24 满负荷运转，通用服务器的供电设计扛不住。CRPS 是 Intel 主导的"行业事实标准"，随 Purley/Whitley/Eagle Stream 平台迭代；M-CRPS 是开放标准，版本透明（2022.11 批准 v1.0 → 现 v1.05 RC5）。

*CRPS vs M-CRPS 关键差异：*

| 维度 | CRPS | M-CRPS |
|------|------|--------|
| 输出电压 | 12V 为主 | 兼容 12V，新增 54V |
| 效率 | 80PLUS 钛金，优化 50% 负载 | 死磕 100% 满载，目标 97%+ |
| 动态响应 | 一般 | 微秒级电流监测，响应负载剧变 |
| 功率密度 | 标准尺寸 1.6-2kW | 同尺寸 4.5kW，+40% |
| 可靠性 | 基础过压/过流保护 | 再浪涌控制 + 黑匣子记录器 |

*54V 的物理动因：* P = U × I。5kW 用 12V 需 400A+，电流大导致线路损耗和发热；升到 54V 电流降为 1/4.5，损耗降低、线缆更细。高功率密度靠 GaN/SiC 器件实现。

*典型 1800W 模块 spec 要点：*

- *尺寸：* 40×73.5×185mm（1U）。185mm 是 1800W 黄金长度；窄版 60mm（SiC/GaN 散热进步），加长 220mm 换 Hold-up 电容空间。体积内压热量是必须上钛金效率的原因。
- *闭环节流 (Closed Loop Throttle)：* 过热时不断电，通过 SMBAlert/PMBus 通知系统，限制输出功率给 CPU 降频/迁移留时间——"带病生存"是业务连续性最后防线。也允许短时超载（1800W 瞬态输出 2100W）。
- *冷冗余 (Cold Redundancy)：* 低负载（<10-20%）时一台休眠只剩 12Vsb，另一台扛全部负载，避开低效率区间，降 PUE；定期轮换主/从延长寿命；唤醒要求 <100ms。
- *浪涌电流控制：* NTC+继电器/电子开关，限制冷启动时大电容短路效应的数百安培瞬时电流，防跳空开/烧整流桥/接头拉弧。
- *有源均流 (Active Current Sharing)：* ISHARE 总线，各模块输出与电流成正比的 Vshare 电压，电压最高者为"标杆"，其余跟随微调输出电压；均流环带宽远低于电压环防振荡。
- *Hold-up Time：* 12-20ms，PFC 输出 380-400V 大电容储能；AC Loss 后提前 2-5ms 拉低 PWR_OK 给 CPU 收尾预警。
- *纹波 ≤1%：* 12V 限 120mV 峰峰值。静态纹波 + 动态跌落叠加不能超芯片 3-5% 容差；纹波电流经 ESR 发热，电解电容温升 10°C 寿命减半。
- *冷启动关键点：* PFC 预充电时序——继电器闭太早 NTC 没限流，直接炸整流桥。
- *Standby：* 12Vsb 独立反激路径，给 BMC 供电（远程开关机/WOL）、维持监控电路，待机功耗 <1W。
