工业四线制霍尔电流/电压传感器（变送器）的端子上印着 `+ - M G` 四个字母，这套命名在国内厂家的手册里高度一致。顺着它能把一个更底层的问题讲清：电源地、参考地、大地到底是不是一回事。地环路与隔离的另一面见 [[can485-isolation-common-mode|CAN 与 485 隔离设计 & 电流采样精度单位]]，BMS 侧的电源域划分见 [[bms-power-design|BMS 电源设计要点]]。

## 端子 + - M G 的定义

- `+`：电源正
- `-`：电源负（**不是 0V** —— 双电源型这里是 -15V / -24V）
- `M`：信号输出端（Measure，测量输出）
- `G`：电源地（0V），**同时是信号输出的公共端**

厂家口径对照：

- 航智 HIT500 的 4PIN 凤凰端子：`+` 供电正极、`-` 供电负极、`M` 输出接口、`G` 电源地（0V）兼信号输出公共端
- 南京信瑞谱 CHCS-HC 端子台：`V+` 电源正、`V-` 电源地(G)、输出信号+、输出信号-(G)
- current-sensors.de CYHCT-KEC 引脚排布：`1(+)`、`2(-)`、`3(O 输出)`、`4(G 接地)` —— 用 `O` 代替 `M`，含义相同

## 双电源与单电源两种接法

**双电源（±15V / ±24V）**

```
+15V ── (+)          M ──┬── RM ── G ── 0V
-15V ── (-)              └── 采集端
 0V  ── (G)
```

二次侧输出是电流，Vo = Io × RM。`G` 是 ± 电源的中点电位，也是输出回路的地。

**单电源（+12V / +24V）**

```
+24V ── (+)     M ── 4-20mA / 0-5V ── 采集端(GND)
 0V  ── (-) 与 (G) 同点
```

这类手册常把「电源地 0」与「信号地 0」分成两个端子 —— 不是重复，是让你分开走线、单点汇合。

**最容易烧设备的一条**：把双电源型的 `-` 当 0V 用，等于给它加 30V 单电源。所有厂家的手册都写「电源正负极不可接错，不可错位」。

## M 上出来的是什么：闭环与开环

- **闭环（磁平衡/补偿式）**：二次侧补偿电流抵消铁芯磁通，`M` 是电流输出，经 RM 转成电压。精度与温漂最好。
- **开环（直测式）**：霍尔元件输出经放大，`M` 多为电压输出（如 CYHCS-KAB 的 Vout）；单电源工业型也常见 4-20mA 电流输出。

部分型号要求 `M`、`G` 输出端反并两只 1N4007（CYHCS-SH 手册明写），保护输出级，不装会烧。

## 「地」的四种含义

| 名称 | 它是什么 | 与 0V 的关系 |
|---|---|---|
| 参考地（0V 基准） | 测量电压的起点，被**定义**出来的电位 | 就是它本身 |
| 电源地（`G` / `V-` / 0V） | 电源输出的负端 | 通常与参考地同点 |
| 保护地（PE / 机壳 / 大地） | 安全地，接机壳与电源线第三根线 | 不一定同点，可能完全隔离 |
| 隔离地（浮地） | 隔离电源副边自己的 0V | 与大地之间只有寄生电容 |

所以「电源地是不是参考地」的答案：**在这台设备范围内是** —— 它是这块电路的 0V 基准，所有电压相对它测量。但它不等于大地，也不等于另一台设备的 0V。参考地不是绝对电位，是被选定出来的节点。

## 隔离不等于「完全断开」：寄生电容

隔离电源/隔离变送器的副边与大地之间存在寄生电容：变压器初次级绕组间电容、副边对机壳的空间电容，有时还有为 EMC 特意加的 Y 电容。直流和工频下隔离阻抗极高（MΩ 级），但高频下容抗下降。

实测数据：一台可调隔离电源的输出对 PE 的电容为 73nF，在 100kHz 下对地阻抗只有约 **21.8Ω**。所以「隔离」隔开的是直流通路，高频共模仍有路可走。

## 测量与接线的四条禁忌

1. **示波器探头的接地夹子接的是 PE**（机壳地，与大地通）。把它夹到隔离副边之外的原边或高压点，等于用夹子把该点对地短路。正确做法是夹在本次测量的参考点上，两点都对地有高共模电压时改用差分/隔离探头或隔离采集卡，两个单端探头的地夹子必须夹在同一点。
2. **不要用「断开示波器电源地线」来浮地**。示波器内部 L/N 对 PE 有 Y 电容，共模电流只是改走电源线；同时机壳会带上被测点电位，有电击风险（Keysight / Tektronix 都明确反对）。
3. **副边的 `G` 不要再连回原边或驱动侧的地**。隔离一旦被击穿，共模干扰进门，重则短路。
4. **手册把电源地与信号地分开标两个 0 时，别随手短接**。分开走线、单点汇合，否则大电流回流路径上的地噪声会灌进信号地，`M` 上的小信号被埋掉。

## 接线前的判别步骤

1. 先看壳上或手册的 Pin Definition，这是唯一依据；没手册先查型号。
2. 万用表电阻档摸底：`M` 与 `G` 之间通常有几十 Ω 到几百 Ω（二次侧内阻/负载，电流输出型）；`+` 与 `-` 之间是电源输入。
3. 上电前确认电源类型（±15V 还是 +24V/0V）与 `M` 侧负载 RM 是否在量程内。
4. 上电后测 `M` 对 `G`：电流输出型读 RM 上的压降再换算；双向电压输出型零电流时约为 Vcc/2，单向 4-20mA 型零电流时是 4mA 对应的读数。
