#+TITLE: 跑步发力——髋主导，不是膝主导
#+STATUS: draft
#+HEADER: Running

* 结论
跑步应该由 *髋关节（臀部）主导发力* ，膝盖是"铰链/缓冲器"，不是发动机。

* 核心区别
- 发力源 :: 髋发力 = 臀大肌（后蹬）+ 髂腰肌（提膝）先动，大腿带小腿，像车轮从髋部摆动；
           膝发力 = 股四头肌/小腿先动，靠膝盖"顶"和折叠蹬地。
- 动作链 :: 髋主导 → 臀部后蹬 → 大腿前抬（髋屈）→ 小腿随摆 → 核心接管缓冲；
           膝主导 → 小腿先甩 → 膝盖过度前顶 → 落地冲击直接砸膝关节。
- 影响   :: 髋主导步幅大、省力、膝盖不易伤；
           膝主导每次落地膝盖吃冲击，易致跑步膝（髌骨股骨疼痛）、髂胫束综合征。

* 常见误区
"高抬腿/提膝"不是膝盖发力——提膝是髂腰肌把整条大腿抬高，*动的是髋* ，膝盖只是顺势弯。
区别在"大腿先动还是小腿先动"。

* 练习方法
1. 臀桥 / 单腿硬拉 :: 唤醒臀大肌
2. 高抬腿走/跑     :: 用髂腰肌把大腿抬到水平
3. 想象"车轮"      :: 腿从髋部像钟摆甩，不是从膝盖弹
4. 收紧核心        :: 核心稳，落地冲击才传不到膝盖

* 一句话
髋是油门，膝是减震器。把发动机放在屁股上，膝盖才能跑得久。
