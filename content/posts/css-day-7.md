今天用 CSS 画了一个圆。[练习 Demo](https://csszengarden.tianheg.xyz/days/first-30-days/7/)。

主要复习了 position 的用法，在圆的中心（从左向右看，从上向下看）画了一个红色的圆点。

还有 blur class 元素与 circle class 元素的先后问题，影响 circle 内部的 dot class 元素在垂直于屏幕的次序。

关键 CSS 属性——[backdrop-filter](https://developer.mozilla.org/en-US/docs/Web/CSS/backdrop-filter)。可为元素添加遮罩滤镜。
