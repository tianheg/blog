两种线材组合算错，几乎都错在同一件事：把“两种线”当成两种规格并列比较。 实际只有两种结构——串联（前段铝缆进柜、后段铜缆上设备）和并联（2×16 代替 32）。 串联是同一个电流流过不同截面，压降逐段相加、载流量取最弱一段； 并联是同一个压降下电流按电导分配，判据变成“每支路都不超载”。两者的算法完全不同，所以分成两个页签。

分段配置

口径说明：基准载流量取 IEC 60364-5-52 / GB/T 16895.15 表 52-C 系列（铜芯、空气 30℃ 或土壤 20℃、直接明敷 / 管槽 / 埋地穿管）。 铜/铝均取标准原表值（不做折算）。土壤热阻修正按 B.52.16，基准 2.5 K·m/W，穿管与直埋分列。埋地成组沿用更严的空气系数。压降按导体最高长期工作温度下的电阻计算（PVC 70℃、XLPE 90℃），忽略电抗， 仅在截面 ≥95mm² 且长距离时会有 1%~3% 的偏差。结果不含短路热稳定（k²S² ≥ I²t）、保护电器选择性、谐波中性线电流的校核，最终以现场条件与产品样本为准。
