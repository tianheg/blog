装机顺序

  1. 先装电源和硬盘笼。ATX 板加 8 盘位机箱通常是分仓结构，电源和硬盘笼在同一个区域，先固定好再上主板。
  2. 主板在机箱外装好 CPU、内存、散热器。LGA2011-3 是方形窄 ILM 扣具，散热器螺丝对角线交替拧，别一次拧到底。
  3. 主板入箱，先接 24pin 和 8pin。8pin 供电口在散热器旁边，装上大散热器之后就够不到了，顺序不能反。
  4. 接硬盘背板供电和 SATA。背板一般需要两个大 4pin；数据线用侧弯头，直头会顶到侧板。
  5. 插扩展卡。两块 M.2 转接卡分别插到不同的 x4 槽（这两个槽共享，用一个 x8 设备时另一个失效）；2.5G 网卡插剩下的槽。
  6. 最小配置点亮。只留 CPU、一条内存，用 IPMI 的 KVM 或主板 VGA 口看画面，进 BIOS 确认核心数、内存容量和通道模式，再装硬盘。

到货验收

  1. 主板 BIOS 版本 ≥ 2.0。低于这个版本不认 v4 CPU，而手上没有 v3 的 U 来刷——这是最容易卡死的一步。
  2. IPMI 能登录。要卖家的 IP 和账号，连上去看传感器读数和 SEL 日志，有硬件报错直接退。没有独显时，IPMI 的 KVM 就是唯一的画面来源。
  3. 10 个 SATA 口逐个认盘。分属 6 个 AHCI 和 4 个 sSATA 两组控制器，RAID 不能跨组（用 ZFS 则不受影响）。
  4. 8 个内存槽逐个过。只插 4 条也要每个槽都试一遍，二手服务器板最常见的问题是内存槽虚焊。
  5. （以后加显卡时）驱动绑定。A380 在 Linux 上默认可能被 xe 驱动抢走，需要钉到 i915，否则转码管线会崩。
  6. CPU 底面检查。LGA 封装没有针脚，看镀金焊盘有无氧化发黑、发绿（铜绿意味着镀金层已穿孔，不可逆）。
