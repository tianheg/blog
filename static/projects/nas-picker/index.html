E5-2690 v4 虚拟化主机

14 核 28 线程、32G REG ECC（RDIMM）起步、10 个原生 SATA、4 个 PCIe 3.0 x16 槽。定位是跑 Proxmox VE：上面开虚拟机和容器，同时承担 NAS 存储。 主板选的是工作站板（Square ILM 扣具），所以散热器和机箱都用消费级产品，不用买服务器配件。当前配置不含独立显卡，硬盘先上一块——E5 没有核显但主板的 BMC 提供 VGA 与 IPMI，装机不需要独显。规格取自各家官方文档，数量可自行调整。

后续可加

主板上有 4 个 PCIe 3.0 x16 槽、8 个内存槽，现在只用掉 1 个槽和 1 条内存。下面几项都可以以后补，不影响现在开工。

Arc A380 硬解卡

只有视频转码时才需要它。局域网用 App 直接播放时服务器不转码，显卡全程闲着；触发转码的情况是浏览器播放、老设备不支持 HEVC、外网带宽不够要降码率、PGS 字幕烧录。加装后支持 AV1 编解码。同价位与更高价位的其他候选、以及本板带不动哪些卡，见下一节对照表。

加第二条 32G 内存

单条 32G 起步，加第二条就升双通道（64G），加到四条是四通道满载（128G）。四通道板的最优是每通道一条或每通道两条。

硬盘扩到 4 块

规划上限 4 盘位，主板的 10 个 SATA 现在只用掉 1 个，机箱有 8 个内置盘位。不需要加 HBA 卡。

最小验机配置

整机配齐之前，先用下面六件把主板、CPU、内存插槽、SATA 口验一遍。二手板最常见的暗病（内存槽虚焊、SATA 口失效、BIOS 版本过低）都能在这一步暴露，坏了直接退，不必等装完才发现。

件要求备注
主板X10SRA-F，BIOS ≥ 2.0下单前让卖家确认版本
CPUE5-2690 v414C/28T，135W
散热器AS120 V2（支持 2011 版）Square ILM 扣具
内存1 × 32G DDR4-2400 REG ECC单条即可 POST
电源ATX，24pin + EPS 8pin有线就能点亮
网线普通千兆线接 IPMI 口远程看画面

这四样先别买：机箱（裸板放绝缘垫上就能点亮）、硬盘（验机只看 BIOS 认不认 SATA）、显卡（主板有 VGA + IPMI，装机不需要独显）、多余内存（1 条够验，4 条是配置阶段的事）。

  1. 裸板点亮。主板 + CPU + 1 条内存 + 电源，主板放在纸板或防静电袋上（不要直接放金属桌面，短路烧板）。接 24pin + 8pin，显示器接 VGA 或网线接 IPMI。
  2. 进 BIOS 只看三样。CPU 型号与核心数（应是 14C/28T）、内存容量、BIOS 版本。三条有一项不对就停手，别继续装。
  3. 8 个内存槽逐个插。只插 1 条，每个槽都试一遍，能 POST 才算过。二手板最常见的问题就是内存槽虚焊。
  4. 10 个 SATA 口逐个认盘。6 个 I-SATA + 4 个 S-SATA；sSATA 那几个在部分 BIOS 版本里默认关闭，只认到 6 个盘时先去 BIOS 打开。

四步全过再去买机箱、硬盘和剩余内存条，把机器装起来。

装机顺序

  1. 先装电源和硬盘笼。ATX 板加 8 盘位机箱通常是分仓结构，电源和硬盘笼在同一个区域，先固定好再上主板。
  2. 主板在机箱外装好 CPU、内存、散热器。X10SRA-F 是 Square ILM 扣具（孔距 80×80mm 正方形），消费级散热器直上；螺丝对角线交替拧，别一次拧到底。
  3. 主板入箱，先接 24pin 和 8pin。8pin 供电口在散热器旁边，装上大散热器之后就够不到了，顺序不能反。
  4. 装硬盘、接 SATA 和电源。消费级机箱用内置托架，硬盘直接插 SATA 数据线和电源线；数据线优先用侧弯头，走线更贴侧板。
  5. 插扩展卡。4 个 x16 槽按 16/16/NA/8 分配：显卡优先插第一个 x16，NVMe 转接卡插剩下的槽；插多张卡时留意单槽会降到 x8。
  6. 最小配置点亮。只留 CPU、一条内存，用 IPMI 的 KVM 或主板 VGA 口看画面。服务器主板默认优先板载视频输出，就算插了独立显卡也要在 BIOS 里改优先级才会亮——所以第一次点亮一律接 VGA 口，别接显卡。进 BIOS 确认核心数、内存容量和通道模式，再装硬盘。
  7. 接机箱前面板跳线。Power SW、Reset SW、HDD LED 这几根线插错是二手主板最常见的翻车点——二手板通常不带说明书，靠猜基本不行。下单时就跟卖家要接线图，比一个个试快得多。
  8. 装完系统把启动模式改成 UEFI。服务器板默认常是 Legacy，PVE 装完拔掉 U 盘会直接引导失败。进 BIOS 的 Boot 页把启动模式切到 UEFI，再装一次引导就好。

到货验收

  1. 主板 BIOS 版本 ≥ 2.0。低于这个版本不认 v4 CPU，而手上没有 v3 的 U 来刷——这是最容易卡死的一步。
  2. IPMI 能登录。要卖家的 IP 和账号，看传感器读数和 SEL 日志，有硬件报错直接退。注意这块板的 IPMI 不支持带外刷 BIOS——BIOS 刷坏只能靠跳线或编程器，所以升级 BIOS 前先确认供电稳定。
  3. 10 个 SATA 口逐个认盘。6 个 I-SATA（C612）+ 4 个 S-SATA（sSATA）；sSATA 那 4 个在部分 BIOS 版本里默认关闭，只认到 6 个盘时先去 BIOS 打开。
  4. 8 个内存槽逐个过。只插 4 条也要每个槽都试一遍，二手服务器板最常见的问题是内存槽虚焊。
  5. （以后加显卡时）驱动绑定。A380 在 Linux 上默认可能被 xe 驱动抢走，需要钉到 i915，否则转码管线会崩。
  6. 要一张前面板接线图。二手主板多半没有说明书，F_PANEL 上 Power SW / Reset SW / HDD LED 的位置各家不同。让卖家给一张接线图，或者拍一张主板丝印特写——装到一半才发现没有图纸很难受。
  7. CPU 底面检查。LGA 封装没有针脚，看镀金焊盘有无氧化发黑、发绿（铜绿意味着镀金层已穿孔，不可逆）。
