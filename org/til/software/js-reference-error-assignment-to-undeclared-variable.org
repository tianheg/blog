*** — title: "JS ReferenceError – Assignment to undeclared variable"
错误代码：

#+BEGIN_SRC js
index = game.initialisingPlayers.indexOf(data.id)
#+END_SRC

正确代码：

#+BEGIN_SRC js
let index = game.initialisingPlayers.indexOf(data.id)
#+END_SRC

或者使用 const。
