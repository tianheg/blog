#+TITLE: 做「行业标准 + 计算工具」小程序：卡人的不是技术，是主体和版权
#+DATE: <2026-10-21 Wed 20:37>
#+STATUS: draft

一篇线缆从业者写的开发记录（[[https://vjo.cc/2019][微信小程序开发日常：线缆工具]]）：把国标检索、线缆试验计算、试验教程、试验数据归档做成一个小程序。功能拆得很实在，但通篇没写技术栈，也没写踩到的合规问题。这篇按「能不能照着做」核对一遍——结论是：*技术上个人完全做得出，真正卡住的是标准文本的版权和小程序主体类型*。

** 原文做了什么

七条需求，去掉客套后是四个模块：

- *国标检索*：按标准号 / 关键词搜，点开在线看 PDF，页面标注发布与实施时间
- *计算工具集*：导体电阻、20℃ 电阻换算、偏心度、椭圆度、成缆外径、节距、每米重量、装盘量、盘具选型、编织密度等
- *试验教程*：31 项，含绝缘电阻、耐压、热延伸、低温、燃烧、护套刮磨等，每项挂对应国标号
- *试验记录*：录入 / 查询 / 打包 ZIP 导出 / 导入恢复，云端存储，用户之间数据隔离

增长机制是邀请码加积分，攒够积分解锁永久使用权。

** 技术侧：PDF 预览只有一条个人能走的路

小程序里看 PDF，方案只有两种，个人主体只够得着一种。

- *wx.openDocument*（可行）：先 `wx.downloadFile` 拿到临时路径，再 `wx.openDocument({filePath, fileType:'pdf'})`。官方支持的 fileType 是 `doc / docx / xls / xlsx / ppt / pptx / pdf`。这是新开页面调起系统级的文档预览，不是内嵌渲染，不能自己控制 UI，但个人主体完全可用。
- *web-view + pdf.js*（个人主体做不到）：`web-view` 组件加载自己的 H5 页面，里面跑 pdf.js 才能实现真正的页面内渲染、跳页、搜索。但微信官方文档写明「*目前小程序内嵌网页能力暂不开放给个人类型账号和小游戏账号*」，业务域名也只支持非个人主体配置。

所以「标准全文检索 + 页面内高亮」这种体验，个人主体的账号做不出来。原文没写它用的是哪一种——如果只是点开看整份 PDF，`wx.openDocument` 就够了；如果宣称能在文内检索，那必然是 web-view 路线，也就意味着它不是个人主体。

顺带一个常被忽略的约束：`downloadFile` 的域名要提前配到「服务器域名」白名单里，且必须 https；否则真机上下载直接失败，开发者工具勾了「不校验合法域名」看不出来。

** 版权侧：这是全文最大的坑，原文一个字没提

国标不是「政府文件」，是有版权的作品。这条链上有三个事实：

- *公开系统自己的声明*：国家标准全文公开系统（openstd.samr.gov.cn）写明「本系统所提供的电子文本仅供个人学习、研究之用，*未经授权，禁止复制、发行、汇编、翻译或网络传播*等，侵权必究」。
- *免费公开 ≠ 放弃版权*：2024 年市场监管总局在答复中明确，「国家标准免费公开并不是对标准出版物版权的放弃」；未经权利人同意、以营利为目的大篇幅复制推荐性标准文本属于侵权。
- *已有判例*：山东高院二审认定推荐性国家标准具有版权，可受著作权法保护，某标准服务商因他人未经许可在网站传播推荐性国标并提供免费阅读下载，获赔 15 万元。

同时政策确实在放宽*获取*：2025 年 2 月起，未采用国际标准的国标开通免费下载，覆盖 3 万余项（含 2.8 万余项推荐性国标）。但「官方让公众下载」和「你把下载来的 PDF 放进自己的小程序分发给别人」是两件事——后者正是声明里禁止的「网络传播」。

对一个自用工具，这没什么问题；一旦上线给同行用、还带邀请积分机制，性质就变了。安全的做法只有三条：

- 只做*标准号与题录检索*，命中后跳官方 openstd 链接，不托管全文
- 托管全文只在自己可见的范围（内部工具、私有部署），不做公开分发
- 把价值放在*计算器和试验教程*上——这些是自己写的，不涉第三方版权

** 产品侧：这个骨架值得抄

抛开版权问题，需求拆分是可以直接复用的模板：

- *检索层*：标准号 / 关键词双入口，结果页显示发布日、实施日、是否现行（版本核对比全文更重要，很多事故是用了作废版本）
- *计算层*：每个计算器一个页面、一个公式、一组默认值；这类工具的价值全在「公式对不对」，不在 UI
- *教程层*：试验项目 → 执行标准的映射表，这是行业新人最缺的东西
- *数据层*：本地优先 + 导出 ZIP + 导入覆盖。原文把数据放云端并要求登录，其实试验记录更适合本地存 + 手动备份，少一个服务器和一套账号体系

** 常见说法核对

- 「国家标准免费公开了，所以可以放进小程序给别人查」——*不成立*。免费公开的是获取渠道，不是著作权；系统页面明文禁止网络传播，且已有判赔先例。
- 「个人也能做 PDF 在线预览」——*部分成立*。`wx.openDocument` 能打开 PDF，但那是调起系统的文档查看器；页面内渲染 / 文内检索必须 `web-view`，而个人主体不支持业务域名与 web-view。
- 「降噪、续航这类参数写进工具里就行」——*要标口径*。厂商参数和自己算出来的量混在一张表里，用户分不清哪个可信；计算器应只输出「按 GB/T XXXX 公式算得」，并给出公式来源。
