#+TITLE: 超微 X10SRL-F 的内存支持与混插规则
#+DATE: <2026-11-05 10:44:19>
#+STATUS: draft

根据超微（Supermicro）官方技术文档，X10SRL-F 主板支持 RDIMM、LRDIMM 以及 3DS LRDIMM 这三种类型的内存，但官方规格页面并未以「2Rx4」或「4Rx4」的形式直接列出支持的 Rank 数，而是通过内存类型和容量来界定。

* 官方支持的内存类型与规格

结合官方规格与内存配置指南，该主板兼容的内存情况如下：

- RDIMM（注册内存）：支持。官方列出的单条容量为 4GB、8GB、16GB、32GB，最高总容量 256GB。2Rx4 结构通常就出现在这类 RDIMM 中（例如金士顿兼容列表里就有 2RX4 的 RDIMM）。
- LRDIMM（减载内存）：支持。官方列出的单条容量为 32GB、64GB，最高总容量 512GB。4Rx4 结构常见于 LRDIMM。需要注意的是，LRDIMM 与 RDIMM 不能混插在同一系统中。
- 3DS LRDIMM：支持。单条容量可达 128GB，最高总容量 1TB。

* 关键配置规则

在给这块主板选配内存时，除了看 Rank 数，更关键的是遵守以下超微的官方规则：

1. 严禁混用类型：RDIMM 和 LRDIMM 不能混插。这是硬性规定，混用会导致无法开机或系统不稳定。
2. Rank 数限制：虽然主板没有明确禁止 4Rx4，但官方内存配置指南指出，每个通道最多允许 8 个逻辑 Rank。同时，如果每个通道插两根内存（2DPC），建议先插 Rank 数高的那条。
3. x4 与 x8 可混插：金士顿的技术说明提到，x4 和 x8 的数据位宽模块允许混用，但不能在同一个 Bank 内混用。

* 选型建议

最稳妥的建议：由于官方规格页没有直接给出 Rank 兼容性表格，如果你手头有特定的 4Rx4 或 2Rx4 内存条，最可靠的方法是去超微官网查询该主板最新的 QVL（内存合格供应商列表），或者直接使用金士顿、三星等厂商官网的「内存搜索」工具，输入 X10SRL-F 来确认具体型号是否通过验证。
