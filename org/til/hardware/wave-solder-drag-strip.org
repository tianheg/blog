#+TITLE: 过炉治具的拖锡片
#+DATE: <2026-11-02 09:32:29>
#+STATUS: draft

今天学到：过炉治具出板端那片不起眼的薄钢片，叫拖锡片（solder drag strip / 接锡片），本质是一个“牺牲件”。

* 为什么需要它

PCB 离开回流焊/波峰焊的加热区那一瞬间，焊点还是液态。板边、工艺边、连接器引脚一失去支撑，熔锡会被顺着拽出来，后果有三类：

- 锡被拖进链条、轨道、炉膛 → 锡珠锡渣污染后板、卡链、掉锡短路
- 板边元件拉尖、连锡、焊量不足、虚焊
- 出板端骤然遇冷空气 → 冷焊

拖锡片把被拖出的熔锡引到自己身上，冷却后落在片上，擦掉或整片更换即可，不让锡留在设备里。

* 长什么样

| 项   | 要点                                                |
|------+-----------------------------------------------------|
| 材质 | SUS304/316 薄板，0.3–0.8 mm                         |
| 表面 | 镀镍或特氟龙不沾锡涂层，方便清理                    |
| 位置 | 治具下游端，沿出板方向延伸，与板边/工艺边搭接       |
| 固定 | 铆接 / 螺丝 / 弹片夹持 / 一次性可撕换               |
| 集成 | 常与导风板、隔热挡板、氮气挡片一体设计              |

* 容易踩的坑

1. 涂层磨损失效 → 锡黏死在片上，反而成为锡渣来源，要定期清理更换
2. 搭接长度不够接不住锡；过长会干涉相邻板或轨道
3. 板边刚好排 BGA/QFN 密集引脚又没留工艺边，怎么加拖锡片都救不回来
4. 回流焊场景重视不够——其实波峰焊拖锡量远大于回流焊，那边才是刚需

* 一句话带走

#+BEGIN_QUOTE
拖锡片不是结构件，是消耗品：用一片便宜的钢片，换掉设备里最难清理、最容易造成批量缺陷的那坨锡。
#+END_QUOTE
